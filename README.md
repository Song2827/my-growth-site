# 我的成长主页 · 个人学习记录与技能展示网页

> 作者：宋伊君（华中科技大学 · 软件工程 2026 级 · 2603 班）
> 技术栈：HTML + CSS + 原生 JavaScript，**零依赖、零构建**，双击 `index.html` 即可打开。

---

## 一、这个网页在做什么

课程作业通常只被看一次就沉进硬盘。这个主页想把「学过什么、做过什么、卡在哪里」累积成一份能长期使用的东西：

- **成长记录**：每条学习记录固定四栏——学了什么、卡在哪、怎么解决、还没解决什么；
- **技能展示**：不写「熟悉 / 了解 / 精通」，每项技能后面都挂证据（作品文件、代码片段、运行截图）；
- **个人名片**：找实习、参加竞赛、申请项目时，可以直接把链接发过去。

## 三、怎么运行

### 1. 直接双击（最快）

双击 `index.html`，浏览器即可正常显示，所有链接都是相对路径，本地也能互相跳转。

### 2. 起本地服务器（推荐，行为与线上一致）

在本文件夹打开终端：

```bash
# 有 Python
python -m http.server 8000
# 或者有 Node.js
npx serve .
```

然后访问 `http://localhost:8000/`。

> 为什么推荐：`file://` 下 `localStorage` 的行为与线上略有差别，用 http 打开能提前发现问题。

### 3. 部署到 GitHub Pages（可选）

1. 把本文件夹内容推到仓库根目录（`index.html` 在根目录）；
2. 仓库 **Settings → Pages → Source** 选 `Deploy from a branch`，分支 `main`、目录 `/ (root)`；
3. 一两分钟后访问 `https://<用户名>.github.io/<仓库名>/`。

## 五、技术说明

| 项 | 做法 |
| --- | --- |
| 布局 | CSS Grid + 自定义属性（颜色、圆角、最大宽度都走变量） |
| 响应式 | 860px / 640px 两档断点；640px 以下导航折叠成抽屉 |
| 交互 1 | 学习记录：标签筛选（全部 / C 语言 / 演示）+ 实时搜索 + 「显示 N / M 条」 |
| 交互 2 | 留言表单：必填、邮箱格式、至少 10 字、失焦即校验、提交后本地保存（`localStorage`，最多 5 条） |
| 交互 3 | 邮箱一键复制（`navigator.clipboard`，不支持时回退到手动复制） |
| 无障碍 | 跳转链接、`aria-current` / `aria-pressed` / `aria-live` / `aria-invalid`、`:focus-visible` 焦点样式 |
| 打印 | `@media print` 隐藏导航与按钮，可直接打印或存 PDF |
| 零依赖 | 不用框架、不用 CDN、不需要构建，离线可用 |

## 六、怎么继续更新（重点）

1. **加一条学习记录**：复制 `learning.html` 里任意一个 `<article class="record card">`，改日期、标题、四栏内容，并更新 `data-tags`（`c` 或 `demo`）和 `data-search`（搜索关键词）。
2. **加一项技能**：复制 `skills.html` 里一张 `.skill-card`，照「做过 / 证据 / 边界」三栏填。
3. **加一个项目**：复制 `projects.html` 里一个 `.project-card`，配图放进 `assets/`。
4. **改首页数字**：`index.html` 的「几个数字」四个 `.fact`。
5. 最后同步一下 `index.html` 的「最近在做什么」。

不需要动导航、不需要动 CSS——这就是这个结构存在的目的。
