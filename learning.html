实验四：编译预处理

学了什么
宏定义、文件包含、条件编译、assert、多文件编译。
卡在哪
宏展开没有括号意识：#define SUM a+b 之后 SUM*DIF 变成 a+b*a-b； SWAP(a,b) a=b,b=a 交换失败；max 里 else 挂在内层 if 上， 输入 3、6、5 返回 5；int i=x 是截断不是四舍五入，assert 当场触发。
怎么解决
宏的参数和整体都加括号；SWAP 补临时变量 t；给外层 if 加花括号； 取整改成 (int)(x + 0.5)。改完输入 5，面积 78.5397、整数部分 79，assert 不再触发。
还没解决
什么时候该用宏、什么时候必须写函数，还没有自己的判断标准。

课堂展示：三版讲稿重写与数据核对

学了什么
把一个村的变化讲成一条因果链（等一个时机 → 政策引领 → 收获成果 → 我），以及公开数据的口径核对。
卡在哪
初稿按「五个问题」平铺，16 页，讲起来散、还超时；投资额、引文、荣誉三处数据在公开报道里口径不一。
怎么解决
重排成「四层叙事」，压到封面 + 14 页正文；讲稿改到第三版，约 2150 字、控时 8 分半到 9 分半， 15 页备注都写了提词与停顿提示；存疑数据逐条查源，查不到的不写。
还没解决
「乡村旅游重点村」的授牌层级始终查不到官方原文，只能按公开报道的措辞写。

实验三：函数与程序结构

学了什么
函数声明与返回类型、参数传递、递归、存储类型，以及用单步跟踪看递归展开。
卡在哪
for 漏了大括号，s+=fac 在循环外只执行一次，求和退化成 n!； fac 未初始化；返回类型写 long，k=20 就溢出。
怎么解决
补大括号、fac=1、返回类型改 long long、格式符改 %lld； 递归版按 1!+…+(n-1)! + n! 拆；级数题用 term = term * x / i， 把每项从「重算幂和阶乘」降为一次乘除。
还没解决
递归层数很深时的栈开销没实测过，不知道到什么规模会出问题。
2026-10-16 · C 语言

实验二：流程控制

学了什么
if / switch、for / while / do-while、 单出口的结构化改造、转移语句。
卡在哪
合数判断器四个错：!x%i（优先级）、if(flag=1)（赋值当判断）、 flag 只在定义时清 0（判过一次合数后全错）、printf 少 \n（结果连成一行）。
怎么解决
依次改成 x%i==0、flag==1，把 flag=0 移进循环体，补换行； 去掉 break 改用 i<=k && flag==0 做单出口； 改 do-while 时前面加 x>3，否则 2、3 会被跳过试除而误判。
2026-10-09 · C 语言

实验一：表达式与标准 I/O

学了什么
运算符优先级与类型转换、getchar / putchar / scanf / printf、位运算。
卡在哪
一个例程改出 9 处错：宏定义多分号、newint 未定义、中文引号、scanf 漏 &、 5/9 得 0 使摄氏温度恒为 0、%f 读 double、printf 输出加 &、 0xa1b2 超出 short、k>>8 是算术右移把符号位补进来。
怎么解决
先编译清语法错，再单步看变量找逻辑错；k 先转 unsigned short 再右移， 得 0x84a1 而不是 0xFFFFFFA1；三题结果与手算一致。
还没解决
输入法混进中文符号这类问题，只能靠写完再通读一遍代码，没有更可靠的办法。
