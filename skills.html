两段代码，两个坑

都从自己的实验报告里摘的，不是示例代码。

① !x%i 与 x%i==0

! 的优先级高于 %，所以 !x%i 实际按 (!x)%i 计算： x 不等于 0 时 !x 是 0，条件永远不成立，一个因子也找不到。 

/* 实验二 · 合数判断器 */
/* 错：(!x) % i 恒为 0，循环走完 flag 还是 0，合数全被判成质数 */
for (i = 2, k = x >> 1; i <= k; i++)
    if (!x % i) { flag = 1; break; }

/* 对：先取余，再和 0 比较 */
for (i = 2, k = x >> 1; i <= k; i++)
    if (x % i == 0) { flag = 1; break; }

代价：编译器不报错，单步时只能看到 flag 一直是 0；改完输入 4 才输出「4 是合数」。

② 宏必须整体加括号

宏是文本替换，不是函数调用。#define SUM a + b 之后写 SUM * DIF， 展开就是 a + b * a - b——乘法先算，平方差直接错。 

/* 实验四 · 平方差 */
/* 错：SUM * DIF 展开成 a + b * a - b */
#define SUM a + b
#define DIF a - b

/* 对：参数和整体都加括号 */
#define SUM (a + b)
#define DIF (a - b)

代价：同样不报错，只是结果偏；换算式也能骗过眼睛，只有把值代进去手算才发现。
